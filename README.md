# 萧山麻将 · XiaoshanMahjong

一个可以在手机浏览器里直接玩的 **萧山麻将**（杭州麻将的加强版）单机游戏：**你 vs 3 个电脑 AI**。
横屏设计，适配折叠屏 / 双屏设备，支持「添加到主屏幕」当成 App 使用。

## 玩法要点

- **牌张**：136 张（去掉 8 张花），每家码 17 墩。
- **财神（百搭）**：四家抓完牌后翻出 1 张牌作为「财神翻牌」，**白板（4 张）为万能百搭牌**，可替代任意牌组成顺子 / 刻子 / 将牌。
- **胡牌**：开局可选
  - `自摸专属`：必须自摸，不能捉冲（点炮）、不能抢杠胡（边锋规则）
  - `允许捉冲`：别人打出的牌也可以胡
- **抢庄制**：谁胡谁做庄，无人胡则连庄。
- **吃 / 碰 / 杠**：吃只吃上家；碰、杠任意家（明杠 / 暗杠 / 补杠均可）；杠后补牌自摸即为「杠开」。
- **财神打出**：白板打出时其他三家不能吃 / 碰（打财神的玩家自己可以继续吃碰）。

## 番型与倍数

| 番型 | 倍数 | 说明 |
| --- | --- | --- |
| 自摸 | ×1 | 基础 |
| 爆头 | ×2 | 胡牌时将牌中含财神 |
| 碰碰胡 | ×2 | 全部面子为刻子 / 杠 |
| 全倒 | ×2 | 面子全部由吃碰杠明牌组成（手中仅剩将牌） |
| 明杠开 | ×2 | 明杠后补牌自摸 |
| 暗杠开 | ×4 | 暗杠后补牌自摸 |
| 财飘 | ×4 | 本局曾打出过财神后仍自摸胡 |
| 七对子（含财神） | ×4 | 七对且用到财神 |
| 清七对（无财神） | ×8 | 七对且全部为天然牌 |
| 清一色 | ×8 | 全部同一花色 |
| 字一色 | ×16 | 全部为字牌 |
| 天胡 | ×16 | 庄家起手 14 张即胡 |
| 地胡 | ×16 | 闲家第一次摸牌即胡 |

倍数可叠加：如 杠开 + 爆头 = 2×2 = 4，杠 + 财飘 = 2×4 = 8。庄家 ×2，二连庄 ×4，三连庄及以上 ×8。单局封顶 64 倍基数。

## 运行

纯静态页面，无需构建：

```bash
# 任意静态服务器即可，例如
npx serve .
# 或直接双击 index.html
```

## 规则实现的说明

以下细节在不同牌局 / 平台上有差异，本项目采用当前采用的解释，均集中在 `js/rules.js` 中，便于按你的牌桌习惯调整：

- 财神以**白板**为万能百搭；翻出的那张牌仅作「本局财神」展示与打出限制判定。
- 「爆头 / 全倒 / 财飘」等方言番型的判定为**推断实现**（依据公开资料），定义见上表。
- 「同一张牌不碰上家就不可以碰下家」这类极冷门的地方细则未实现。
